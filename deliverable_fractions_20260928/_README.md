## Overview

These files show flow and sediment output from the Watershed Dynamic Model.

---

## Notes

 1. The attached CSV files are time series of streamflow (m³/s) and suspended sediment concentration (mg/L) for the 44 pour points of the In-bay model.
 
 2. Each file contains output for a pour point, from WY 1995 to WR 2025.
 
 3. Each column shows:  
    Date: YYYY-MM-DD  
    flow_cms: dicharge (m³/s)  
	ssc_mg_L: total sediment concentration (mg/L)  
	ssc_sand_mg_L: sand concentration (mg/L)  
	ssc_silt_mg_L: silt concentration (mg/L)  
	ssc_clay_mg_L: clay concentration (mg/L)  	
	
 4. Output was derived from WDM run120
